Local remediation guide

Understand the service before changing the machine.

Use Run in PowerShell to execute the read-only owner check directly in the dashboard. Nmap Guardian can also stop and verify a narrowly defined Python or Node test server on ports 3000, 8000, or 8080. It never automatically stops Windows core services, changes firewall rules, patches software, or stops its own port 5000.

01

Identify

Record the port, service name, version information, owner, and whether it is expected. An open port is an observation, not automatic proof of a vulnerability.

02

Reduce exposure

For a temporary development server, stop it after testing. Where supported, configure it to bind to 127.0.0.1 instead of all network interfaces.

03

Verify

Run a new localhost scan. Keep the before/after results and explain whether the target port is now closed or still needed.

Controlled course demo

Python web-server example

  1. Start a local-only web service: python -m http.server 8000 --bind 127.0.0.1
  2. Scan it in Nmap Guardian and document port 8000.
  3. Open its command plan and use Stop test process + verify, or stop it with Ctrl+C.
  4. The dashboard immediately creates a new scan and shows port 8000 under Newly closed.

For Windows Firewall or other system services, use operating-system documentation and make changes only when you are the authorized administrator. Record the action before rescanning.
